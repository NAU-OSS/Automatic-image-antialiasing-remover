# Automatic-image-antialiasing-remover
Most images have antialiasing, sometimes I need to remove it to create good resizable svgs, bitmap images, and embroidery files. This project should turn the process into something instant.
# Installation Instructions
To install this product currently you will need to compile the main code file using gcc to compile it. New installation instructions will emerge as we move closer to a release version.

# Examples of usage
To use this file you will have an input.png image and the file will generate an output.png image in the same folder with the de-antialiased image.
