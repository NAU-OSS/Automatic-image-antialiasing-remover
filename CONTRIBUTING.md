# How to contribute
Start by creating a branch and editing/adding relevant code. When you are ready to commit and merge back to the main branch create a pull request and have it reviewed by an admin (currently only castdeath7) then after any relevant issues are resolved we can send it to main.

# Code style and Formatting
We currently don't require specific coding style or formatting, just make sure to comment in your code the purpose of each addition.

# Testing requirements 
We don't have any tests at the moment, except for we will make sure gcc compiles

# Documentation standards
When committing files make sure to describe the changes you are making

# How to report bugs
If you find a bug create an issue, mark it as a bug for said request and @castdeath7 for review of the issue. Make sure to provide a description of the issue, an example, operating system, and how to recreate the issue.

# How to propose new features
If you would like to propose a new feature create a new issue, mark it as a feature and explain said feature to the best of your ability.

# Community Guidelines and Expectations 
We expect people in this open source community to generally be polite to one another. Failure to do so may result in a ban from the repository.
