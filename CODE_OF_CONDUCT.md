# Expected Community Behavior 
We expect all members to act with respect to all other community members. There is no purpose in fighting about non-project related issues in this repo, so that is specifically not allowed.

# Unacceptable Behavior examples
Political fights in the repo
Cursing at eachother
ect....

# How to report violations
Send a message to @castdeath7

# Enforcement Guidelines
If users fail to comply with this policy twice in 1 year they will be removed from the repo

# Community values and principles
We value productive members that are polite to others
